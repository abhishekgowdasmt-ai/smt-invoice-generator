Run these commands only after 001_smt_dev_schema.sql has committed.
Connect as the local PostgreSQL superuser. psql prompts for the password twice.
The password is not written into this file, the command line, the schema plan, or the Flask environment file.

If psql is on PATH:

psql -h 127.0.0.1 -p 5432 -d smt_dev -U postgres -c "\password smt_app"

If PostgreSQL 16 was installed in the default Windows location:

"C:\Program Files\PostgreSQL\16\bin\psql.exe" -h 127.0.0.1 -p 5432 -d smt_dev -U postgres -c "\password smt_app"

The same step inside an interactive session:

psql -h 127.0.0.1 -p 5432 -d smt_dev -U postgres
\password smt_app
\q

PostgreSQL 15 and 16 store the result with password_encryption, which is scram-sha-256 unless the server setting was changed.
Do not put the password in an ALTER ROLE statement.
